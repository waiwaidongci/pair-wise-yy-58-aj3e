# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、**测绘基准/厂家模型基准统一换算**、净空结论台账、冲突定位、双扫描仪并提处理和多角色签署工作流。

## 基准换算与净空结论

现场扫描点按**现场测绘基准版本**入库，厂家模型使用**厂家模型基准版本**。两套基准通过简化七参数（三轴平移 + 绕 Z 旋转 + 尺度）折算到同一套“统一数学框架（canonical）”后再比较：

- `src/datum.ts`：纯几何内核——`toCanonical / fromCanonical / migratePointCoords / transformBox / boxGap / minClearance`（旋转后的包围盒取轴投影外包 AABB，偏安全侧）。
- `src/store.ts`：
  - 登记基准版本与换算参数（`registerDatum / activateDatum`）；
  - 每个步骤计算构件统一框架位置与最小净空，低于 1.5m 自动生成高优先级冲突项；
  - 厂家换版：**未发布且引用旧基准的结论立即作废（stale）并按新参数重算；已发布的保留原依据、原净空，仅标“待复核”**，复核通过后另出新结论、原依据留存；
  - 旧实测点换版时经统一框架迁移，**原值归档为历史数据**（冻结在旧基准），现行点写入迁移后坐标；缺实测的步骤按厂家模型 8 角点回填（标注“模型回填”）；
  - 两台扫描仪并提同一构件：**先到占用本次结论，后到并入待复核**；在待复核项上“保存冲突”即**保留全部现场测量**、切换占用并自动**下重测条**，复测后闭环；
  - 每条净空结论都带 `manufacturerDatumId + siteDatumId` 双基准版本徽章；操作全程写入审计流水。

种子数据预置了可演示的结论翻转叙事（阈值 1.5m）：

| 步骤 | MFR-V1 | MFR-V2（tx=-0.5, rotZ=0.02） |
| --- | --- | --- |
| S-02 南侧障碍 | 1.30 超限 | 1.59 合格（旧冲突消除） |
| S-04 回转轴线 | 1.80 合格 | 1.47 超限（新发现冲突） |
| S-03 试吊 | 模型 1.58 / 现场实测 1.46 | 扫描仪 A 先到占用、B 后到待复核 |

页面右上角“重置演示数据”可随时回到初始状态。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

端口：`62058`

```bash
npm run build
```

数据草稿保存在浏览器 `localStorage`（键 `yy58-lift-datum-v2`，与旧版草稿不兼容时自动回落种子数据），Apollo 内存缓存保存吊装方案版本快照。
